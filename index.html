Luồng 01 · Mở hồ sơ chủ thể

Tách bạch danh tính của một chủ thể khỏi vai trò của họ: danh tính chỉ có một, vai trò có thể có nhiều. Hồ sơ = ID chủ thể + Nghiệp vụ + Vai trò. Gồm 4 luồng con.

1.1Mở ID chủ thểOutput · ID chủ thể 1.2Gán quan hệOutput · ID quan hệ 1.3Gán vai tròOutput · ID vai trò 1.4Mở hồ sơ theo Nghiệp vụOutput · ID hồ sơ

1.1 Mở ID chủ thể

Input

Bắt buộc

  • Loại chủ thể
  • Loại giấy tờ định danh
  • Giá trị định danh
  • Nguồn tạo
  • Tên gọi

Không bắt buộc

  • Giới tính
  • Ngày sinh / ngày thành lập

Process

  1. 1.1.1Kiểm tra đủ trường bắt buộc và đúng định dạng theo loại chủ thể Fail — báo lỗi và chỉnh sửa Pass — sang bước 2
  2. 1.1.2Tra trùng theo cặp loại – giá trị giấy tờ Đã tồn tại — thông báo "Thông tin đã tồn tại" Chưa tồn tại — sang bước 3
  3. 1.1.3Tạo ID Sinh mã ID mới Cài đặt trạng thái: Hoạt động

Output

  • ID chủ thể
    • Trạng thái

1.2 Gán quan hệ

Input

Bắt buộc

  • Hai đầu quan hệ
    • ID bên A
    • ID bên B
  • Loại quan hệ

Không bắt buộc

  • Thời gian hiệu lực
    • Ngày bắt đầu hiệu lực
    • Ngày kết thúc hiệu lực

Process

  1. 1.2.1Kiểm tra 2 ID Đang hoạt động Không trùng nhau
  2. 1.2.2GỌILuồng Thẩm định và phê duyệt (nếu cần) — thẩm định điều kiện mối quan hệ Chấp thuận — sang bước 3 Từ chối — kết thúc luồng
  3. 1.2.3Gán quan hệ Ghi nhận thời gian hiệu lực (nếu có) Cài đặt trạng thái: Hoạt động

Output

  • ID quan hệ
    • Trạng thái
    • Hiệu lực

1.3 Gán vai trò

Input

Bắt buộc

  • ID chủ thể
  • Loại vai trò

Không bắt buộc

  • Thời gian hiệu lực
    • Ngày bắt đầu hiệu lực
    • Ngày kết thúc hiệu lực

Process

  1. 1.3.1Kiểm tra chủ thể đang hoạt động Fail — báo lỗi Pass — sang bước 2
  2. 1.3.2GỌILuồng Thẩm định và phê duyệt (nếu cần) — thẩm định điều kiện vai trò Chấp thuận — sang bước 3 Từ chối — kết thúc luồng
  3. 1.3.3Gán vai trò với khoảng hiệu lực Trạng thái = Hoạt động

Output

  • ID vai trò
    • Trạng thái
    • Hiệu lực

1.4 Mở hồ sơ theo Nghiệp vụ

Input

Bắt buộc

  • ID chủ thể
  • ID vai trò
  • Nghiệp vụ

Process

  1. 1.4.1Kiểm tra chủ thể đang hoạt động Fail — báo lỗi Pass — sang bước 2
  2. 1.4.2GỌILuồng Thẩm định và phê duyệt (nếu cần) — thẩm định hồ sơ Chấp thuận — sang bước 3 Từ chối — kết thúc luồng
  3. 1.4.3Tạo hồ sơ Sinh mã hồ sơ Khoảng hiệu lực

Output

  • ID hồ sơ
    • Trạng thái
    • Hiệu lực
